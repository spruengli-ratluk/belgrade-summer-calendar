# Belgrade Summer Calendar 2026

Interactive calendar by Sprüngli & Ratluk (Lara Stanić and Andreas Pfister).

## Publish with GitHub Pages

1. Upload all files and folders from this package to the root of the repository.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, choose:
   - Source: **Deploy from a branch**
   - Branch: **main**
   - Folder: **/(root)**
4. Click **Save**.

The site will then be published at:

`https://aendu778.github.io/belgrade-summer-calendar/`

## Important

Keep this folder structure unchanged:

- `index.html`
- `styles.css`
- `app.js`
- `assets/calendar-background.png`
- `assets/videos/`
- `assets/posters/`

GitHub Pages is case-sensitive, so file names must remain exactly as they are.
